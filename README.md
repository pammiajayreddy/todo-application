
# TaskFlow - Todo Application

TaskFlow is a responsive task management web application built with
HTML, CSS, and vanilla JavaScript. It helps users organize daily
activities, track progress, and manage task priorities.

## Features

- Add tasks with low, medium, or high priority.
- Mark tasks as completed or active.
- Delete individual tasks.
- Filter tasks by All, Active, and Completed.
- Clear all completed tasks.
- View total, completed, and remaining task counts.
- Automatically save tasks using browser localStorage.
- Responsive design for desktop and mobile devices.
- Display the current date.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Browser localStorage
- Git and GitHub

## Data Storage

Tasks are stored locally in the browser. They are not
synchronized between browsers or devices.
